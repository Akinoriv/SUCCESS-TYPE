### ✅ Изменено

#### Логика персонализации

**Было:**

```typescript
personalizeQuestions(questions, user) {
  return questions.map(q => ({
    ...q,
    text: getPersonalizedText(q.variations, user)
  }));
}
```

**Стало:**

```typescript
personalizeQuestions(questions, user) {
  return questions.map(q => ({
    ...q,
    text: getPersonalizedText(q.variations, user),
    options: personalizeOptions(q.options, user) // НОВОЕ!
  }));
}
```

### 💡 Технические детали

#### Структура variations в БД:

```json
{
  "options": {
    "А": {
      "text": "Забыл про нее, увлечен чем-то новым",
      "variations": {
        "default": "Забыл про нее, увлечен чем-то новым",
        "male": "Забыл про нее, увлечен чем-то новым",
        "female": "Забыла про нее, увлечена чем-то новым"
      },
      "score": 4
    }
  }
}
```

#### Приоритет персонализации:

1. Ищет ключ по gender пользователя (male/female)
2. Если не найден - использует "default"
3. Если default нет - берёт первое доступное значение
